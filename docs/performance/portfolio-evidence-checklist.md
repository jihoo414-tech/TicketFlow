# Portfolio evidence checklist

- Record the test environment, workload, quality criteria, and measurement date.
- Compare results only when the scenario and environment are equivalent.
- Report repeated measurements and their variability, not only the best run.
- Distinguish a measured result from a hypothesis about its cause.
- Include both seat lookup and hold latency when evaluating cache changes.
- Confirm concurrency test results and final database state before publishing claims.

References: `aws-report.md`, `seat-count-report.md`, and `../concurrency-cases.md`.
