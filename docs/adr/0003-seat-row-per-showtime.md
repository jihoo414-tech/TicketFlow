# 좌석은 회차마다 한 행으로 저장

좌석은 "특정 회차에 속한 지정석 하나"다. 그래서 공연장 배치를 한 벌만 두고 회차와 조합하지 않는다. 대신 회차마다 좌석 행을 따로 만든다(`seat.showtime_id`, 회차 안에서 열·번호 유니크). 참조는 좌석 → 회차 → 공연 방향이다.

**선택 이유 (사용자)**: 동시성을 제어하기 위해 각 좌석별로 락을 적용하기 위해서다.

## Considered Options

- **좌석 위치(`seat_position`)를 한 벌만 두고, 좌석을 (회차, 위치) 조합으로 보기**: 데이터는 작지만 DB에 좌석 행이 없다. 그래서 좌석 행을 잠그거나 좌석에 상태를 두는 선택지가 사라진다. 채택하지 않았다.

## Consequences

- 좌석 행이 회차 수 × 좌석 수만큼 생긴다. 지금 규모에서는 문제가 되지 않는다.
- 회차의 모든 좌석은 같은 가격이므로 가격은 좌석이 아니라 회차에 둔다. 좌석 등급이 생기면 다시 판단한다.
